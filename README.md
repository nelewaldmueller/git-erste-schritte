# Git: Erste Schritte

Ich habe in der Vorlesung gelernt, wie Git Änderungen in Commits festhält, Branches paralleles Arbeiten ermöglichen und Tags Versionsstände markieren. Da Git verteilt arbeitet, hat jeder die komplette Historie lokal und Plattformen wie GitHub erleichtern die Teamarbeit

## Fachbegriffe
- **Repository:** Ablage eines Projekts mit allen Dateien und der gesamten Verlaufshistorie
- **Commit:** gespeicherter Stand zusammengehöriger Änderungen mit Metadaten
- **Branch:** bewegliche Referenz auf einen Commit, der eine eigene Entwicklungslinie darstellt
